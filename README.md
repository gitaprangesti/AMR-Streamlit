# AMR Surveillance Dashboard

An integrated machine learning project for analyzing antimicrobial resistance (AMR) patterns and supporting public health surveillance.

## Project Overview

This project combines data processing, machine learning, model evaluation, and interactive visualization to explore antimicrobial resistance risks across countries and years.
